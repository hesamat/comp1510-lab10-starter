# COMP 1510 Lab 10 - The Loan Desk

Follow the lab handout (PDF) for the full requirements.

`loans.py` is the program you complete. `days_of` is finished and
correct; `longest_loan` is finished but the desk has been crashing:
run the program before you change anything. `load_loans` is finished
too, but it comes up short on `loans_messy.csv`: Part 3 of the
handout asks you to repair it. The two CSV files are the desk's
data. Leave them as they are, and leave them beside `loans.py`,
where the bare filenames in the handout resolve.

Write the suite in `tests/test_lab10.py`: one example test ships with
the boundary part, and every other test is yours. Test each function
before you implement it.

`main()` grows as you go: Part 2 prints the shelf map at startup, and
Part 3 adds the load and the numbered longest-first listing.

Submit `loans.py` and `test_lab10.py` to the Lab 10 dropbox in
Learning Hub before the deadline.
